02

Why 5M first

5M is a sensible first target for testing the complete pipeline: tokenizer, data, training loop, checkpoint saving and resuming. A small run fails fast and costs little.

Once training is reliable and checkpoints save correctly, a 10M version can be investigated. Later models in the family are meant to start from Genesis weights instead of random initialization.

Carry-over from Dust

Check before training

Dust's saved tokenizer registers <|assistant|| at ID 3, while generation uses <|assistant|>. Every model that starts from Genesis inherits its token IDs, so print each special token, confirm the exact strings, and back up the tokenizer before the first run.

Interpretation & next checks

Positive signal

Both training and validation loss decreased substantially. The model is improving at next-token prediction on the reported data.

Not yet conversational

Baseline generations were incoherent. Loss improvement alone does not establish coherent writing or reliable question answering.

Outstanding diagnostic

The saved tokenizer reports malformed special token <|assistant|| at ID 3, while generation uses <|assistant|>. Determine whether this mismatch affected training before changing tokenizer IDs or continuing training. The source of <unk> and � also remains to be confirmed.
